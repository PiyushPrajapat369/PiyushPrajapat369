👋 About Me
Hi, I’m an MCA (Master of Computer Applications) student who loves working with technology, especially in AI, programming, and cyber security awareness.
I enjoy building AI assistants that can listen, understand, and perform tasks like a human helper. I like experimenting with voice commands, automation, and finding ways to control PCs and browsers using AI.
At the same time, I keep improving my programming skills and try to spread awareness about cyber security so people can stay safe online.

🚀 What I Do

Build AI assistants using voice and automation
Work with Python, APIs, and system tools
Explore how AI can control computers and browsers
Learn and share knowledge about cyber security

🎯 My Goal
To create smart AI tools that can help people in daily life and encourage safe use of technology.
